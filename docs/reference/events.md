# Events

### createRule
$createRule: options \dashrightarrow \emptyset$
Creates an EventBridge rule.

### deleteRule
$deleteRule: name \dashrightarrow \emptyset$
Deletes an EventBridge rule.

### hasRule
$hasRule: name \dashrightarrow boolean$
Checks if an EventBridge rule exists.

### getRule
$getRule: name \dashrightarrow rule$
Retrieves an EventBridge rule.

### getRuleARN
$getRuleARN: name \dashrightarrow string$
Retrieves the ARN for an EventBridge rule.
