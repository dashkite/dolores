# SNS

### get
$get: name \dashrightarrow topic$
Retrieves an SNS topic.

### create
$create: name \dashrightarrow topic$
Creates an SNS topic.

### publish
$publish: topic, message \dashrightarrow \emptyset$
Publishes a message to an SNS topic.

### subscribe
$subscribe: topic, protocol, endpoint \dashrightarrow \emptyset$
Subscribes an endpoint to a topic.
