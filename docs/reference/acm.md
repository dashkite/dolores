# ACM

### hasCertificate
$hasCertificate: domain \dashrightarrow boolean$
Checks if an issued certificate exists for the given domain.

### getCertificate
$getCertificate: domain \dashrightarrow certificate$
Retrieves the metadata for a certificate matching the domain.

### getCertificateARN
$getCertificateARN: domain \dashrightarrow string$
Gets the ARN of the certificate for the given domain.
