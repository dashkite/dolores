# Roles

### createRole
$createRole: options \dashrightarrow \emptyset$
Creates an IAM role.

### deleteRole
$deleteRole: name \dashrightarrow \emptyset$
Deletes an IAM role.

### hasRole
$hasRole: name \dashrightarrow boolean$
Checks if an IAM role exists.

### getRole
$getRole: name \dashrightarrow role$
Retrieves an IAM role.

### getRoleARN
$getRoleARN: name \dashrightarrow string$
Gets the ARN of an IAM role.
