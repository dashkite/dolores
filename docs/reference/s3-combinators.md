# S3-Combinators

### bucket
$bucket: name \to function$
Combinator function to set the S3 bucket.

### key
$key: name \to function$
Combinator function to set the S3 key.

### body
$body: content \to function$
Combinator function to set the S3 body.

### type
$type: contentType \to function$
Combinator function to set the S3 content type.

### cache
$cache: config \to function$
Combinator function to set the S3 cache control.

### put
$put: \dashrightarrow \emptyset$
Combinator function to execute the S3 put operation.
