# S3

### getBucketARN
$getBucketARN: name \to string$
Returns the ARN of the bucket.

### hasBucket
$hasBucket: name \dashrightarrow boolean$
Checks if an S3 bucket exists.

### putBucket
$putBucket: name \dashrightarrow \emptyset$
Creates an S3 bucket if it doesn't exist.

### deleteBucket
$deleteBucket: name \dashrightarrow \emptyset$
Deletes an S3 bucket.

### deleteDirectory
$deleteDirectory: name, prefix \dashrightarrow \emptyset$
Deletes all objects under a specific prefix in a bucket.

### emptyBucket
$emptyBucket: name \dashrightarrow \emptyset$
Empties an entire S3 bucket.

### getBucketLifecycle
$getBucketLifecycle: name \dashrightarrow lifecycle$
Retrieves a bucket's lifecycle configuration.

### putBucketLifecycle
$putBucketLifecycle: name, lifecycle \dashrightarrow \emptyset$
Applies a lifecycle configuration to a bucket.

### deleteBucketLifecycle
$deleteBucketLifecycle: name \dashrightarrow \emptyset$
Removes a bucket's lifecycle configuration.

### putBucketPolicy
$putBucketPolicy: name, policy \dashrightarrow \emptyset$
Applies an IAM policy to a bucket.

### deleteBucketPolicy
$deleteBucketPolicy: name \dashrightarrow \emptyset$
Removes a bucket's policy.

### putBucketWebsite
$putBucketWebsite: name, config \dashrightarrow \emptyset$
Configures a bucket for static website hosting.

### deleteBucketWebsite
$deleteBucketWebsite: name \dashrightarrow \emptyset$
Removes a bucket's website configuration.

### putBucketRedirect
$putBucketRedirect: name, target \dashrightarrow \emptyset$
Configures a bucket to redirect to another host.

### headObject
$headObject: name, key \dashrightarrow metadata$
Retrieves metadata for an object without downloading it.

### hasObject
$hasObject: name, key \dashrightarrow boolean$
Checks if an object exists in a bucket.

### getObject
$getObject: name, key \dashrightarrow object$
Retrieves an object from a bucket.

### putObject
$putObject: bucket, key, body \dashrightarrow \emptyset$
Uploads an object to a bucket.

### deleteObject
$deleteObject: name, key \dashrightarrow \emptyset$
Deletes a single object from a bucket.

### deleteObjects
$deleteObjects: name, keys \dashrightarrow \emptyset$
Deletes multiple objects from a bucket.

### listObjects
$listObjects: name, prefix \dashrightarrow array$
Lists objects in a bucket under an optional prefix.

### getUploadURL
$getUploadURL: name, key, contentType \dashrightarrow string$
Generates a pre-signed URL for uploading an object.

### putCORSConfig
$putCORSConfig: input \dashrightarrow \emptyset$
Configures CORS on a bucket.

### deletePublicAccessBlock
$deletePublicAccessBlock: name \dashrightarrow \emptyset$
Removes the public access block from a bucket.
